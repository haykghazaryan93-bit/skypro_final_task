Git

  • git init — создать новый локальный репозиторий в текущей папке.
  • git clone — скопировать удаленный репозиторий на компьютер.
  • git status — показать текущее состояние файлов (измененные, новые, удаленные).
  • git branch — посмотреть список локальных веток.
  • git switch <имя> или git checkout <имя> — переключиться на нужную ветку.
  • git config --global user.name "Имя" — указать имя пользователя для всех репозиториев.
  • git config --global user.email "email@example.com" — указать почту для всех.
  • git add . — добавить все измененные файлы в индекс (подготовить к коммиту).
  • git pull — скачать изменения с сервера и сразу слить их с текущей веткой.
  • git push — отправить локальные коммиты в удаленный репозиторий.
