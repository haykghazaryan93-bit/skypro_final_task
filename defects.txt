Файл git.html
Заменены команды mac на команды git:
1. ls -> git init — создать новый локальный репозиторий в текущей папке.
2. cd -> git clone <url> — скопировать удаленный репозиторий на компьютер.
3. pwd -> git status — показать текущее состояние файлов (измененные, новые, удаленные).
4. mkdir -> git branch — посмотреть список локальных веток.
5. mv -> git switch <имя> или git checkout <имя> — переключиться на нужную ветку.

Добавлены команды git:
1. git config --global user.name "Имя" — указать имя пользователя для всех репозиториев.
2. git config --global user.email "email@example.com" — указать почту для всех.
3. git add . — добавить все измененные файлы в индекс (подготовить к коммиту).
4. git pull — скачать изменения с сервера и сразу слить их с текущей веткой.
5. git push — отправить локальные коммиты в удаленный репозиторий.
